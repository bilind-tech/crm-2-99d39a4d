- [x] WhatsApp-Story-Datenmodell, Bildspeicher und geschützte API auf dem Pi
- [x] Story-Vorlage und neue Werkzeug-Seite einbinden
- [x] Bildimport per Auswahl, Drag-and-drop und Zwischenablage
